# 🚗 HopOn – Campus Ridesharing App

> A modern, mobile-first ridesharing app designed for students. Built with HTML, CSS & JavaScript.

## 🌐 Live Demo
**[View App → chijiokke.github.io/HopOn](https://chijiokke.github.io/HopOn/)**

---

## ✨ Features

| Feature | Description |
|---|---|
| 🛡️ Onboarding | 3-slide animated carousel with swipe support |
| 🔐 Login / Sign Up | Google & Apple SSO + email/password form |
| 💬 Chat | Real-time messaging with typing indicators & auto-replies |
| 🚗 Rides | Browse, search & filter available rides |
| ⭐ Ratings | Star rating system for completed trips |
| 🌙 Dark Mode | Full deep-purple dark theme |
| 📍 Map Previews | SVG route maps on each ride card |
| 💰 Price Calculator | Auto-suggest ride pricing |
| 📱 PWA | Installable on phone like a native app |
| 🔌 Offline | Works without internet via service worker |

## 📱 Install as an App (PWA)
1. Open the live URL in Chrome on your phone
2. Tap **⋮ menu → "Add to Home Screen"**
3. HopOn installs on your home screen like a real app!

## 🛠️ Tech Stack
- **HTML5** — Semantic structure
- **CSS3** — Variables, animations, glassmorphism, dark mode
- **Vanilla JavaScript** — No frameworks, no dependencies
- **PWA** — Service Worker + Web App Manifest
- **Google Fonts** — Montserrat

## 🚀 Running Locally
Just open `index.html` in any browser — no build step needed!

For hot-reload development, use [VS Code Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer).
